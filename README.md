# Pixelchi 724\n\nوب‌سایت پیکسلچی ۷۲۴؛ استودیوی خلاقیت، طراحی و چاپ.\n

گالری نمونه محصولات در بخش «نمونه محصولات» صفحه اصلی قرار دارد. برای تغییر تصاویر، فایل‌های پوشه assets را جایگزین کنید و نام فایل‌ها را در index.html هماهنگ نگه دارید.


گالری نمونه محصولات شامل دو اسلاید معرفی برند و نمونه‌های چاپی است. پوشه assets را همراه فایل‌های اصلی در GitHub بارگذاری کنید.
